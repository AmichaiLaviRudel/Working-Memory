CREATED FILES:
--------------

1. glm_fitting.py
   - Main GLM fitting module with all core functions
   - Implements Poisson GLM regression for neural data
   - Includes 9 behavioral predictors:
     * Cue Onset (stimulus presentation)
     * Stimulus (frequency)
     * Category (Go vs NoGo trial type)
     * First Lick (timing)
     * In-Trial Lick Count
     * Reward (Hit trials)
     * Punishment (False Alarm trials)
     * Previous Trial Outcome
     * Trial States (wait, sound, delay, response window durations)

2. example_glm_usage.py
   - Complete working examples
   - Demonstrates single unit and population analysis
   - Includes visualization functions for results
   - Shows integration with existing workflow

3. GLM_README.md
   - Comprehensive documentation

   - Easy import: from single_unit_offline_analysis import fit_glm_for_unit


KEY FEATURES:
-------------

✓ Poisson regression model (appropriate for spike counts)
✓ L2 regularization (prevents overfitting)
✓ Feature standardization (comparable coefficients)
✓ Statistical significance testing (Wald test p-values)
✓ Cross-validation (5-fold CV for generalization)
✓ Pseudo R² metric (McFadden's)
✓ Flexible predictor selection
✓ Batch processing for multiple units
✓ Integration with existing Unit class


MAIN FUNCTIONS:
---------------

1. fit_glm_for_unit()
   - Fit GLM for a single unit
   - Returns dictionary with coefficients, p-values, R², etc.

2. fit_glm_for_all_units()
   - Fit GLM for all units in a dataset
   - Returns pandas DataFrame with results
   - Optional CSV export

3. build_design_matrix()
   - Construct predictor matrix from behavioral data
   - Flexible predictor inclusion/exclusion
   - Handles missing data gracefully

4. fit_glm_poisson()
   - Core GLM fitting function
   - Poisson regression with regularization
   - Statistical testing and cross-validation


QUICK START:
------------

# Import
from Analysis.NPXL_analysis.single_unit_offline_analysis import (
    fit_glm_for_unit,
    fit_glm_for_all_units,
)

# Single unit
glm_results = fit_glm_for_unit(
    unit_data=unit.unit_data,
    time_bins=unit.time_axis,
    stimuli_outcome_df=unit.stimuli_outcome_df,
    bin_size=unit.bin_size,
    time_window=(0.0, 0.5),
    category_boundaries=(0.983, 1.525),  # Go/NoGo boundaries
)

# All units
glm_df = fit_glm_for_all_units(
    units=units,
    category_boundaries=(0.983, 1.525),  # Go/NoGo boundaries
    save_to_csv=True,
    output_path="glm_results.csv"
)


OUTPUT FORMAT:
--------------

GLM Results Dictionary:
- coefficients: List of feature coefficients
- intercept: Model intercept
- feature_names: Names of predictors
- p_values: Statistical significance
- pseudo_r2: Model fit quality (0-1)
- deviance: Model deviance
- cv_score: Cross-validation score

DataFrame Columns (all units):
- unit_idx, region_name
- glm_pseudo_r2, glm_deviance, glm_cv_score
- glm_coef_[feature]: Coefficient for each feature
- glm_pval_[feature]: P-value for each feature

NOTES:
------

- GLM requires at least 10 trials per unit for stable fitting
- Features are automatically standardized for comparability
- Cross-validation helps detect overfitting
- P-values assume large sample approximation (>30 trials recommended)
- Poisson model assumes firing rate is non-negative
